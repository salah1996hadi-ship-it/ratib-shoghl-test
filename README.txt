رتّب شغلك - الإصدار التطويري V2.2.1

الموجود في هذه النسخة:
- إعادة تصميم الواجهة الأساسية بتصميم متجاوب وألوان زمردية وكريمية ولمسات ذهبية.
- تحسين الأزرار والأيقونات والبطاقات.
- إضافة نوع النشاط التجاري واسم المحل إلى ملف النشاط الحالي.
- إضافة قسم أولي للزبائن مع معلومات الاتصال والعنوان والبحث.
- نموذج مخزون مطور: اسم المنتج، رمز/باركود، نوع التعبئة، عدد التعبئات المشتراة، عدد الوحدات في التعبئة، الوحدة الأساسية، سعر شراء التعبئة، سعر الجملة للتعبئة، سعر المفرد للوحدة، حد تنبيه المخزون، الصلاحية والمورد.
- حساب إجمالي الوحدات وتكلفة الوحدة وإجمالي الشراء في معاينة قبل الحفظ.
- حفظ المنتج وحركة الشراء الأولية معاً بعملية Firestore batch واحدة.
- الاحتفاظ بتوافق الحقول القديمة quantity و price و cost، وبمسارات المستخدمين الحالية.

مهم:
- هذه نسخة تطويرية للاختبار وليست إصداراً إنتاجياً نهائياً.
- لا تستبدل النسخة المنشورة الحالية قبل الاختبار بحساب تجريبي.
- لم يكتمل بعد خصم المخزون تلقائياً عند البيع أو شاشة تحويل/تعديل المخزون أو إدارة فواتير الشراء التفصيلية.
- لم يكتمل بعد الموردون والتسديدات التفصيلية والموظفون والفروع والاشتراكات.
- لا تدخل بيانات حقيقية قبل اكتمال الاختبارات.


تحديث V2.2 — ربط المبيعات بالمخزون:
- شاشة البيع تتيح اختيار منتج أو عدة منتجات في الفاتورة الواحدة.
- اختيار البيع بالمفرد أو بالتعبئة/الجملة، وإدخال الكمية.
- يحسب النظام قيمة البيع وتكلفة البضاعة والمتبقي تلقائياً.
- ينفذ البيع داخل Firestore transaction: يقرأ أرصدة المنتجات أولاً، ويتحقق من كفاية المخزون، ثم يحفظ الفاتورة ويخصم الوحدات الأساسية ويسجل حركات خروج المخزون ضمن العملية نفسها.
- إذا كان المخزون غير كافٍ أو سعر الجملة غير محدد، تُرفض العملية ولا تُحفظ الفاتورة.
- المبيعات القديمة تبقى كما هي ولا تُخصم منها كميات بأثر رجعي.

مهم: تم فحص JavaScript نحوياً فقط. لم يُجرَ اختبار متصفح أو اختبار اتصال فعلي بقاعدة Firebase؛ لا تنشر النسخة على الموقع الحي قبل اختبارها بحساب تجريبي ومنتجات تجريبية.


مراجعة V2.2.1:
- تم تعديل احتساب كميات التعبئة داخل Firestore transaction اعتماداً على بيانات المنتج المقروءة حديثاً من قاعدة البيانات، بدلاً من الاعتماد على نسخة الواجهة القديمة.
- تم تجميع كميات المنتج الواحد داخل المعاملة والتحقق من الرصيد قبل أي كتابة.
- تم منع كمية الجملة الكسرية، ومنع المبلغ المستلم السالب، والتحقق من أسعار البيع والتكلفة.
- اجتاز JavaScript فحص الصياغة بواسطة Node.js.
- ما زال يلزم اختبار المتصفح واتصال Firebase بحساب تجريبي؛ لم يتم تنفيذ اختبار حي على قاعدة البيانات.
